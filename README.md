# Rian Vitor

### Cybersecurity · Information Security

Information Systems student with a background in software development and database
analysis, now working toward a career in information security. I like the parts of this
field where you have to prove what happened: packet captures, logs, evidence, and a
written conclusion someone else can reproduce.

**Right now my focus is fundamentals** — networking, Linux, and learning to read what a
system leaves behind.

🔍 **Open to internships** in security analysis / SOC, AppSec & DevSecOps, cloud security,
infrastructure security or digital forensics. Still early enough to go deep in whichever
direction the work takes me.

## 📚 Courses & practice

Leaving this here in case it's useful to someone else starting out. Everything on this
list is free or has a usable free tier.

**Courses that issue a certificate**

| Course | Provider |
|---|---|
| [Hackers do Bem](https://hackersdobem.org.br/) | MCTI · RNP · SENAI-SP (🇧🇷, free) |
| [AWS Skill Builder](https://skillbuilder.aws/) — Cloud Practitioner | AWS |
| [AWS Educate](https://aws.amazon.com/education/awseducate/) — Getting Started with Security | AWS |
| [Introduction to Cybersecurity](https://www.netacad.com/) | Cisco Networking Academy |
| [Junior Cybersecurity Analyst](https://www.netacad.com/) | Cisco Networking Academy |
| [NSE 1 & NSE 2](https://training.fortinet.com/) | Fortinet |

**Where I practice**

| Platform | What it's good for |
|---|---|
| [TryHackMe](https://tryhackme.com/) | Guided paths — the gentlest start, and genuinely fun |
| [Hack The Box](https://www.hackthebox.com/) | Harder machines, less hand-holding |
| [OverTheWire — Bandit](https://overthewire.org/wargames/bandit/) | The best way to actually learn the Linux shell |
| [LetsDefend](https://letsdefend.io/) | Blue team: alert triage in a simulated SOC |
| [CyberDefenders](https://cyberdefenders.org/) | Blue team labs with real artifacts and PCAPs |
| [picoCTF](https://picoctf.org/) | CTF fundamentals, free and always available |
| [VulnHub](https://www.vulnhub.com/) | Vulnerable VMs to run offline in your own lab |
